# Mat på Fat – utkast till ny hemsida

Ett förslag på en ny, enkel enkelsidig hemsida för [matpafat.se](https://www.matpafat.se).

- `index.html` – all text och struktur (svenska)
- `style.css` – design (färger överst under `:root`)
- `img/` – foton från nuvarande sajt, nedskalade för snabbare laddning

Öppna `index.html` i en webbläsare för att titta. Sidan är helt statisk och kan
hostas gratis på t.ex. GitHub Pages eller Netlify.

## Att göra innan publicering
- Lägg in riktiga "från"-priser och gärna en exempelmeny (PDF)
- Lägg till ett par kundomdömen
- Byt offertformuläret till en riktig formulärtjänst (t.ex. Formspree) om
  förfrågningar ska komma utan att besökarens mejlprogram öppnas
- Fler bilder på lokalen i Rollsbo
